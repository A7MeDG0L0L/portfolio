# Ahmed Galal — Portfolio

Personal portfolio of **Ahmed Galal**, Mobile Application Developer (Flutter & Android) in Cairo.
Bilingual (English / Arabic, RTL), with an interactive phone hero where every project is an app.

- **Stack:** Astro 7, Tailwind CSS 4, TypeScript. Static output, no backend.
- **Quality bar:** unit tests (Vitest), browser tests on desktop + mobile (Playwright), Lighthouse ≥ 95 in every category.

## Structure

| Path | What |
|---|---|
| [`site/`](site/) | The website: run, test, deploy and content-editing guide in [`site/README.md`](site/README.md) |
| [`docs/superpowers/specs/`](docs/superpowers/specs/) | Design spec |
| [`docs/superpowers/plans/`](docs/superpowers/plans/) | Implementation plan |
| [`mockups/`](mockups/) | The three design directions explored before building |

## Quick start

```bash
cd site
npm install
npm run dev -- --ignore-lock
```
